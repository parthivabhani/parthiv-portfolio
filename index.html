✦ Project 02

2026 · Applied AI · Technical assessment for Wenup

Document Intake Assistant

A chat that turns a conversation into a validated record and a draft document. The LLM proposes, the code decides.

  • The model proposes field updates as strict JSON; tested TypeScript validates every one, rejects contradictions and owns the state.
  • Never crashes on a bad model: one repair retry, then a fallback chain of five models across Groq, Gemini and OpenRouter.
  • 138 automated tests and 14 live model evals. The draft is a pure function of validated state, exported as PDF or text.
